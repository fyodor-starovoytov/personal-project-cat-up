### User has 4 screens.

## app-menu-view
Logo/name
First screen user stumbles upon. 3 Buttons to choose where to proceed.

## cat-up-view
The pop-up screen in the corner, where user will get the notifications. Clicking the notification will swoosh it away or open its location.

## customization-view
Customize the look of the notification screen and some other settings for the application, like the notification sound.
